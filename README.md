# My Budget Tracker

## Project Description

My Budget Tracker is a simple web-based project designed to help users keep track of their income and expenses. The project was built using HTML and CSS.

The website provides an expense form where users can enter expense information and an expense table where sample expenses are displayed.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
  - Merriweather
  - Open Sans
