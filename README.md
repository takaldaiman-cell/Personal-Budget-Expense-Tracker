# My Budget Tracker

## Project Description

My Budget Tracker is a simple web-based project designed to help users keep track of their income and expenses. The project is currently built using HTML and CSS.

The website provides an expense form where users can enter expense information and an expense table where sample expenses are displayed.

## What I've Built So Far

So far, I have built and styled the following features:

* Created the main Budget Tracker webpage
* Added an expense form
* Added fields for expense name, amount, and category
* Added expense categories such as Food, Transport, Rent, Entertainment, and Other
* Created an expense table with sample expenses
* Added a budgeting tips video
* Added instructions explaining how to use the tracker
* Added Google Fonts
* Added a page title
* Added a favicon
* Added Open Graph meta tags
* Published the website using GitHub Pages
